## 二维码生成接口

下面是发现的两个国内速度不错的二维码接口。

**1.QR Code Generator**

德国人开发的，历史悠久，支持`https`

**接口格式**：

```http
https://api.qrserver.com/v1/create-qr-code/?size=尺寸&data=链接
```

其中尺寸可以是`100x100`、`150x150`等等。如果格式错误或不填写，默认为`250x250`。

支持的参数比较多，请看[官方文档](https://goqr.me/api/doc/create-qr-code/)。

**接口示例**：

<https://api.qrserver.com/v1/create-qr-code/?size=300x300&data=https://trezedo.gitee.io>

<br/>

**2.QRCODE.JP**

日本人开发的，已经稳定十余年了，同样支持`https`

**接口格式**：

```http
https://qrcode.jp/qr?q=链接&s=尺寸
```

其中尺寸可以填数字`1-10`，可以查看[主页地址](https://qrcode.jp/)。

**接口示例**：

<https://qrcode.jp/qr?q=https://trezedo.gitee.io&s=10>
