# 数据结构练习题 - 双向循环链表

$$
\def\boxTwo(#1,#2){\begin{array}{|c|c|}\hline \!#1\! & \!#2\!\\ \hline \end{array}}
\varnothing\leftarrow
\boxTwo(a,b)
\leftrightarrows
\boxTwo(c,d)
\to \varnothing
$$
