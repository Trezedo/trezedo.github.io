# 2020-07-03 积分题

::: info 题目

计算不定积分 $\ds I=\int{\frac{1}{\sin ^6x+\cos ^6x}\d x}$ .

:::

<!-- more -->

注意到恒等式

$$
\left( a^6+b^6 \right) =\left( a^2+b^2 \right) \left( a^4-a^2b^2+b^4 \right)
$$

因此

$$
\begin{aligned}
    \sin ^6x+\cos ^6x&=\left( \sin ^2x+\cos ^2x \right) \left( \sin ^4x-\sin ^2x\cos ^2x+\cos ^4x \right)\\
    &=\cos ^4x\left( \tan ^4x-\tan ^2x+1 \right)
\end{aligned}
$$

从而

$$
\begin{aligned}
    I&=\int{\frac{\sec ^4x}{\left( \sin ^6x+\cos ^6x \right) \sec ^4x}\d x}=\int{\frac{\left( 1+\tan ^2 \right) \sec ^2x}{1-\tan ^2x+\tan ^4x}\d x}\\
    &\xlongequal{u=\tan x}\int{\frac{1+u^2}{1-u^2+u^4}\d u}=\int{\frac{\frac{1}{u^2}+1}{\frac{1}{u^2}-1+u^2}\d u}\\
    &=\int{\frac{1}{\left( \frac{1}{u}-u \right) ^2+1}\d \left( u-\frac{1}{u} \right)}=\arctan \left( u-\frac{1}{u} \right) +C\\
    &=\arctan \left( \tan x-\cot x \right) +C\\
\end{aligned}
$$
