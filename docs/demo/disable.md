# 布局与功能禁用

你可以通过设置页面的 Frontmatter，在页面禁用功能与布局。

<!-- more -->

本页面就是一个示例，禁用了如下功能:

- 导航栏
- 侧边栏
- 路径导航
- 页面信息
- 贡献者
- 编辑此页链接
- 更新时间
- 上一篇/下一篇 链接
- 评论
- 页脚
- 返回顶部按钮
